# 土地マップ

[路線価ウォーカー](https://dead-or-alive.pages.dev/rosenka-walker/) を参考にした、地図から国税庁の路線価図PDFを表示するビューアです。

## できること

- 住所検索、または地図クリックで該当の路線価図を表示
- 地図上に図郭（ページ範囲）を重ねて表示
- 年度一覧からの切替・東西南北の隣接図移動
- 国税庁ページ・倍率表・宅地造成費へのリンク
- Googleマップ（航空写真・ラベル表示切替）
- 道路種別・用途地域・土砂災害マップを同じ地点で表示

## 含めないもの

- 公図へのジャンプ
- 他サービスへの誘導（「こちらもいかが」など）

## 外部設定

### アイコン

`icon/main_icon.ico` を差し替えてください（タイトル横とファビコンに使います）。表示できない形式の場合は同フォルダの `main_icon.png` にフォールバックします。差し替え後はブラウザをハードリロードしてください。

### 地図の初期位置

`config/settings.json` を編集します。

```json
{
  "map": {
    "lat": 35.50715,
    "lon": 139.61745,
    "zoom": 15,
    "label": "新横浜駅"
  },
  "gmap": {
    "scale": 1500,
    "labels": true
  },
  "gis": {
    "zoom": 16,
    "mps": 2500
  }
}
```

| キー | 意味 |
|------|------|
| `gmap.scale` | Googleマップタブの目標縮尺（例: 500 = 1/500） |
| `gmap.labels` | 航空写真のラベル初期表示（画面上のボタンでも切替可） |
| `gis.zoom` | 道路種別・用途地域・土砂災害マップのズーム |
| `gis.mps` | 同タブで縮尺分母を渡す地図サイト向けの値 |

サーバー再起動は不要です（ハードリロードで反映）。

### 道路種別・用途地域・土砂災害マップの参照先

`config/maps.json` が地図サイトの登録簿です。表示中の地点から次の順で参照先を選びます。

- `muniFirstPrefs`（東京都・神奈川県・千葉県・埼玉県）… **市区町村 → 都道府県 → 全国**
- それ以外の道府県 … **都道府県 → 全国**

登録簿の書式は次のとおりです。`url` には `{lat}` `{lon}` `{z}` `{mps}` を埋め込めます。

```json
{
  "muni": {
    "神奈川県": {
      "横浜市": {
        "zoning": { "name": "横浜市行政地図情報提供システム", "url": "https://..." }
      }
    }
  }
}
```

`"embed": false` は枠内に表示できないサイトです（`X-Frame-Options` による拒否、または利用許諾の同意が別サイトのフレーム内では保存されないもの）。この場合は次のように動きます。

- より広い範囲（都道府県版・全国版）に枠内表示できる地図があれば、それを枠内に表示し、本来の参照先は「別タブで開く」ボタンで案内します
- どれも枠内表示できなければ、「地図を開く」ボタンのカードを表示します
- 参照先が未登録の地点では、公開先を検索するリンクを表示します

## 起動方法

### かんたん起動（Windows）

`start.bat` をダブルクリックしてください。初回は依存パッケージのインストールが自動で走り、その後ブラウザで http://localhost:5173 が開きます。

### コマンドで起動

```bash
npm install
npm start
```

ブラウザで http://localhost:5173 を開いてください。

## 技術構成

| 役割 | 内容 |
|------|------|
| 地図 | Leaflet + 地理院タイル |
| 図郭特定 | `rosenka-core.js`（国税庁索引図＋町丁名索引＋GSIジオコーダ） |
| PDF表示 | pdf.js（CDN） |
| CORS回避 | Express `/api/rosenka-proxy` |

国税庁サイト・地理院APIへのアクセスは教育・個人利用の範囲で行ってください。商用利用時は[国税庁の案内](https://www.rosenka.nta.go.jp/copyright.htm)を確認してください。
