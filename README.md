# 路線価チェッくん

地図クリック／住所検索で国税庁の路線価図PDFを表示するビューアです。

## 他のPCで使うとき

1. このフォルダをコピーする
2. `路線価チェッくん.lnk` または `start.bat` を実行する

Node.js が無い場合は、起動時に **LTS 版を自動インストール**します（初回のみ。失敗時は管理者として再実行してください）。追加の `npm install` は不要です。

ブラウザが開き、`http://localhost:5173` で使えます。終了は起動ウィンドウで `Ctrl+C`。

## できること

- 住所検索・地図クリックで路線価図を表示
- 図郭の重ね表示、年度切替、隣接図移動
- Googleマップ／関連マップ（用途地域・道路種別・土砂災害）への位置連携
- 東京特別区の境界付近では近隣区の図も選択可

## 設定

| ファイル | 内容 |
|----------|------|
| `config/settings.json` | 初期地図位置・縮尺 |
| `config/maps.json` | 関連マップのリンク登録簿 |
| `icon/ro_kanji.ico` | アプリ／ショートカットのアイコン |

## 技術メモ

- サーバーは Node.js 標準ライブラリのみ（依存パッケージなし）
- 国税庁・地理院への通信は同一オリジンのプロキシ経由
- Node.js 未導入時は `winget`、だめなら公式 MSI のサイレントインストールを試行
